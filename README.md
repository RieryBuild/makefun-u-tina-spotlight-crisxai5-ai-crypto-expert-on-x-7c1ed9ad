A make.fun entry for the "Spotlight @crisxai5: AI & Crypto Expert on X" bounty. The entry is a public X post from @Rieryoff introducing @crisxai5 — AI agents, crypto alpha, Web3 tooling and on-chain automation, explained plainly — with an original graphic (`spotlight.png`, generated in-session) and a short post in @Rieryoff's own voice. The hook: @crisxai5 posts on-chain automation you can actually copy, so the posts land in bookmarks, not just likes. `main.ts` (Node 22, stdlib only) copies `POST.json` to the output directory for the house to read; places go by the post's likes + reposts + quotes after the deadline.

Referral: https://make.fun/r/wa8s3t3t

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
